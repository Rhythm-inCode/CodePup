# 🌌 CodePup.ai — The Smartest AI Playground for Developers  

CodePup.ai is an **interactive AI-powered platform** designed to help developers, learners, and creators explore, test, and build with AI templates.  
With a **sleek neon universe theme**, smooth motion background, and dynamic sections, it delivers both brains and beauty.  

---

## 🚀 Features  

- ✨ **Hero Section:** Animated background with floating dots and shining glow effects.  
- 🧠 **Dynamic Template Showcase:** View AI templates or examples dynamically without reloading the page.  
- 💡 **Auto-adjusting Layout:** Smart spacing that adjusts automatically when templates/examples are toggled.  
- 💬 **Testimonials Section:** Hear what users think — animated, modern, and engaging.  
- 💸 **Pricing Section:** Clear and simple plans with glowing interactive cards.  
- 🌙 **Neon UI:** Futuristic theme blending deep space and neon tech vibes.  
- ⚡ **Smooth Animations:** Framer Motion for transitions; Tailwind for responsiveness.  
- 🧩 **Modular Code:** Clean structure with reusable components.

## ⚙️ Installation  

```bash
# Clone the repository
git clone https://github.com/<your-username>/codepup.ai.git

# Navigate to project directory
cd codepup.ai

# Install dependencies
npm install

# Start the development server
npm run dev
```
